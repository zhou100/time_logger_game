# gstack-office-hours

Use this skill for fast, practical review of product proposals.

## Lenses
1. Privacy & policy
   - Data minimization
   - Sensitive inference handling
   - Retention and deletion
   - User control / transparency
2. Core product alignment
   - Keeps product simple?
   - Increases actionability?
   - Respects user agency?
3. Engineering reality
   - Complexity and failure modes
   - Cost/latency impact
   - Eval + observability plan

## Deliverable
- Red flags (blockers)
- Yellow flags (monitor)
- Required mitigations before launch
- 1-week trial plan

## Rule of thumb
If privacy control or user override is missing, recommend **No-Go** for broad rollout.
