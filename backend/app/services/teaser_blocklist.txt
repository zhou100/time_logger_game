# Teaser blocklist — Porter stems that must NEVER surface as a demo teaser.
#
# Two categories:
#   1. Profanity / slurs — these never go in front of a user, even if they
#      passed the allowlist. Curated from common public-domain profanity
#      lists; deliberately tight to avoid being a moderation list.
#   2. Common English first names — Porter stems are often confused for
#      these (e.g. "mary" -> "mari" matches "marri" sometimes), and a
#      teaser of "you mentioned 'mike' twice" is creepy when the user
#      never said it. We block ~200 of the most common US/UK first names.
#
# TODO: expand to ~1000 first names from a public-domain census source
# before launch. The smaller list ships first to keep this commit reviewable.
#
# Lines starting with `#` and blank lines are ignored. Each entry is a
# Porter stem (the algorithm in app/services/_porter.py) lowercased.
